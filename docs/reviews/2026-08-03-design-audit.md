## Находки

### Critical

#### C1. Default-egui-font-everywhere — `main.rs:40`, `ui/mod.rs:200`
*(аналог веб-антипаттерна «Inter-everywhere»)*
Приложение использует шрифт egui по умолчанию во всём: заголовки, тело, цифры, лейблы. Нет `FontDefinitions`, нет пары семейств, нет шкалы размеров. Для Swiss Style типографика — единственный держатель иерархии; сейчас иерархии нет вообще.
→ Ввести пару: grotesk display (IBM Plex Sans / Inter Tight) + уточнённый body; типошкала из 4–5 шагов.

#### C2. Token improvisation / нет дизайн-системы — по всем `ui/*_page.rs` (~30 инлайнов)
*(антипаттерн «Mid-render token improvisation», Hallmark gate 48)*
Цвета захардкожены `Color32::from_rgb(...)` прямо в коде. Семантический «зелёный ОК» существует в **трёх** значениях: `0x00,0x64,0x00` (`check_page.rs:198`), `0x20,0x66,0x20` (`mod.rs:68`, `report_page.rs:128`), `32,112,55` (`license_page.rs:207`). «Красный ошибка» — `0xa8,0x00,0x00` (большинство), `165,25,25` и `145,35,35` (`license_page.rs:151,226`). «Янтарный предупреждение» — `0x9a,0x5b,0x00`, `155,85,0`, `150,85,0`. Один смысл — три разных hex.
→ Ввести единый токен-блок (`colors.rs`/`tokens`): `OK`, `ERROR`, `WARN`, `PAPER`, `INK`, `ACCENT`, категории `CAT_*` — и ссылаться только по именам.

### Major

#### M3. Dated pastel category palette — `ui/mod.rs:20-27`
`#d9ead3 #c9daf8 #fff2cc #f4cccc #cfe2f3 #d9d2e9` — в точности дефолтные «fill color» из Google Sheets/Docs 2010-х. Это и есть «слабоватость», которую чувствует пользователь: не AI-слоп, а визуально-устаревший toolbar-пастель. Цвет должен нести информацию (категория действия), а не штамп из старого тулбара.
→ Сохранить семантику категорий (paste/open/action/rotate/mirror/copy), заменить на нейтрально-серый + один хроматический акцент (Swiss); категории различаются позицией/надписью/монохромной штриховкой, а не пастелью.

#### M4. Нет типографической иерархии — `ui/mod.rs:40-42`
`section_title` = `RichText::new(text).strong()` — просто жирный, того же размера и семейства, что body. Заголовок раздела неотличим от лейбла. Swiss требует градаций (display → heading → label → mono-метка).
→ Типошкала: заголовок раздела display, лейблы body, числовые метки моно с `tabular-nums` (аналог gate 40 — цифры в «X: 12 -> 8» сейчас пропорциональны, `check_page.rs:199`).

#### M5. Несогласованность семантических цветов между страницами — `license_page.rs:207-239` vs `check_page.rs:127,198`
`license_page` имеет собственную лестницу статусов (green `32,112,55`, blue `45,92,145`, amber `155,85,0`, red `165,25,25`, gray `95,95,95`) — отдельную от `0xa8,0x00,0x00`/`0x00,0x64,0x00` остального приложения → две дизайн-системы в одном окне.
→ Одна система статусов на всё приложение (см. C2).

#### M6. Смешанный язык углов — `preview.rs:132,213`, `report_page.rs:305,308` vs виджеты egui
Свотчи `Rounding::ZERO` (острые), но кнопки/лейблы наследуют дефолтные ~4–6px egui. Нет единой дисциплины. Для Swiss/industrial это чинится в **нужную** сторону: `Rounding::ZERO` глобально = чёткий индустриальный грид.
→ Единое правило углов (0px для индустриального, или 2px компромисс); явно через `ctx.style()`.

#### M7. Произвольные отступы — `PAGE_SPACING=6.0` (`mod.rs:18`), margin 6/8, item spacing 4 (`mod.rs:241`)
Шаги 6/8/4 не на шкале 4pt/8pt, нет воздуха. Swiss требует ритмичную сетку.
→ Шкала 4pt: `4/8/12/16/24`; `PAGE_SPACING` → 8, item spacing → 8, margins → 12.

### Minor

#### m8. Pure black/white — `preview.rs:217`, `report_page.rs:309` (`BLACK`), `preview.rs:132,378` (`WHITE`)
Чистые `#000`/`#fff` выглядят плоско (аналог «Pure black, pure white»). Свотчи-обводки и заливки Canvas.
→ Тонировать: ink `oklch(20% 0 0)` вместо чёрного, paper `oklch(98% 0.002 240)` вместо белого.

#### m9. Nav fill `from_rgb(240,240,240)` — `mod.rs:236`
Почти-белый без привязки к токену paper. Отдельный hex для одной панели.
→ Через токен `PANEL_BG` (на ~2 шага темнее paper).

#### m10. Монопольные `Color32::from_hex(...).unwrap_or(LIGHT_GRAY)` — `check_page.rs:274,297,320` и др.
Пастель категории передаётся строкой-hex и парсится в рантайме; fallback `LIGHT_GRAY` — другой visual-язык. Громоздко и хрупко.
→ Хранить категории как `Color32`-константы в токен-блоке.

## Summary — **2 critical · 5 major · 3 minor**

## Verdict — **reads as dated & underdesigned, not AI-slop**

Честный ответ на «убедись что дизайн не является AI-слопом»: **это не AI-слоп.** Классических веб-tells нет — нет фиолетового градиентного hero, 3-колоночных фич-карточек, glassmorphism, эмодзи-иконок, выдуманных метрик. Это написанный вручную egui-инструмент. «Слабость», которую чувствует пользователь, — **устаревшая toolbar-пастель + отсутствие дизайн-системы** (типографика, токены, шкала), а не генеративный слоп. Swiss Style лечит именно это: убирает пастель 2010-х, вводит нейтральный + один акцент, строит иерархию на типографике и сетке 4pt.

Все находки чинятся **без смены каркаса и положения кнопок** (ограничение пользователя): правки идут в `ui/mod.rs` (палитра + типошкала + `ctx.set_visuals`/`set_style`), новый `colors.rs`/tokens, и замену инлайн-`from_rgb` на вызовы по именам — формы, страницы, сигнатуры `show()` не трогаются.

## Направление редизайна (ориентир для `hallmark redesign --mood swiss`)

- **Токены:** нейтральная серая шкала (paper → ink), один хроматический акцент; категории-action различаются позицией/моно-меткой, не пастелью.
- **Типографика:** grotesk display + body; шкала 4–5 шагов; `tabular-nums` на числовых метках.
- **Сетка:** 4pt (`4/8/12/16/24`); `PAGE_SPACING=8`, item spacing=8, margins=12.
- **Углы:** `Rounding::ZERO` глобально (индустриальный грид) — единое правило через `ctx.style()`.
- **Статусы:** одна лестница (ok/warn/error/info) на всё приложение, вместо трёх «зелёных» и трёх «красных».
- **Carry-over:** каркас, страницы, положение и семантика кнопок, нав-лист 9 страниц — без изменений.
